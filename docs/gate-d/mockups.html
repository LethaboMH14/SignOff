For review before any console code

  1. Should Paid need both the Warden's settled record and the agent's RECONCILED record? These mockups assume both.
  2. Should the receipt re-check the ledger each time it opens? These mockups assume yes.
  3. The rand rate is a placeholder. Who sets it, and should the rate's date be shown?
  4. A raise needs a different operator. Should a pending raise expire after 24 hours? M3 shows 23 hours left as a proposal.
  5. Account numbers show only the last four characters. Agree for screenshots and the video?
  6. Until RLUSD runs, receipts say test-issued token, not RLUSD. Agree?
  7. PC and phone are both required from the first console change, not added at the end. Agree?
